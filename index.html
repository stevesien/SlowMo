SlowMo

Slow-motion minimize, back on modern macOS.

Mac OS X used to have a party trick: hold Shift while you minimize a window and it slowly melts into the Dock. Apple switched it off in macOS High Sierra, but the animation is still in the Dock. SlowMo switches it back on, and lets you choose which key to hold.

Install

  1. Download SlowMo-1.0.dmg and open it.
  2. Drag SlowMo into Applications, then open it from there.
  3. A tortoise appears in the menu bar. The Dock restarts once (it flickers for a second) and slow motion is on.

Use it

Hold Shift and click a window's yellow ● button, or press ⌘M while holding Shift. The window minimizes in slow motion. The same works for un-minimizing it from the Dock.

To use a different key, click the tortoise and choose one under Hold this key while minimizing: Fn / Globe, Control, Option, Command, or any regular key you press.

Shift needs no permissions. Any other key needs Accessibility access, because SlowMo has to watch for that key and quietly hold Shift down for the Dock while you press it. macOS asks the first time; you can also turn it on in System Settings → Privacy & Security → Accessibility.

Menu

  • Slow-motion minimize: turns the effect on or off (restarts the Dock).
  • Hold this key while minimizing: Shift, Fn, Control, Option, Command, or a custom key.
  • Open at login: start SlowMo automatically.
  • Quit SlowMo.

With Shift as the key, SlowMo doesn't even need to keep running once the effect is on. The Dock remembers the setting. Keep it running if you use another key.

Privacy

SlowMo has no network code at all. It doesn't collect, store or send anything. It changes one Dock setting (com.apple.dock slow-motion-allowed) and, for non-Shift keys, listens for your chosen key on this Mac only.

Remove it

  1. Click the tortoise and untick Slow-motion minimize to put the Dock back the way it was.
  2. Quit SlowMo and drag it from Applications to the Trash.
  3. If you gave it Accessibility access, remove it from that list in System Settings.

Why isn't it on the Mac App Store?

App Store apps run in Apple's sandbox, which doesn't allow changing the Dock's settings or restarting it. SlowMo can't work under those rules, so it's distributed directly. It's still signed with a Developer ID and notarized, so macOS opens it without warnings.
